# 示例会议纪要与体验步骤

## 首选：保管合同会议纪要

导入 [meeting-minutes-custody.md](meeting-minutes-custody.md)，或复制全文到输入框。示例明确要求《保管合同 GF—2000—0801》，也可在完整模板库搜索“保管合同”后查看原件、自行选择。

验收重点：安澜是保管人、青禾是寄存人；20箱模型；期限至2027年1月31日而非已否决的2月28日；全期费用3000元（叁仟元整），不是4500元或每月3000元；分两次各1500元支付。申报价值不是赔偿上限；不编造账号、瑕疵结论、特殊温湿度、赔偿、留置或争议解决方案。

核对并确认已有内容后，点击“一键忽略未确定空白”，确认统一留空原因即可处理全合同空白，不受分页或筛选影响。已有值、已审核项和未保存修改不会被覆盖；有内容的分歧仍需核对。至少确认一项有效非空值，且其余项均已审核或留空，才可预览导出待完善草稿。以后取消对应字段的“保留空白”，补充、确认、刷新预览并重新生成；历史导出文件不会自动更新。

括号内可定位的“是/否、有/无”已纳入选择字段；未知选项留空会恢复原文字。第六条“不含货币等”可据记录提取“否”；第四条瑕疵、第五条额外特殊措施及第十二条留置未确定，不应擅选。第九条原件写成“保管人允许保管人”，存在角色歧义，系统不擅改固定文字；请检查并人工维护，不能只机械填“否”。核对箱号、申报价值不等于赔偿上限、交接清点与期满取回是否落入合适字段，留意全合同覆盖检查。金额原件已有“元”，本格应填“叁仟”而不是“叁仟元整”。请继续检查未识别空白、其他选项及附件。缺失信息暂留空不代表草稿可直接签署。没有密钥也可手动填写；以上预期不是模型准确率认证。

所有示例均为虚构测试数据，不代表真实交易、法律意见或可直接签署的合同。

## 导入示例

启动应用、注册登录后，新建合同任务，导入同目录的 `meeting-minutes-equipment-purchase.md`，或把内容复制到记录输入框。点击分析后，核对点名的《工业品买卖合同 GF—2000—0101》是否优先出现，再预览原件、由用户选择模板。

该原件确实存在于当前模板库。若找不到推荐，可在完整模板库搜索“工业品买卖合同”。名称匹配只证明找到原件，不代表已经证明业务适用性。

选择模板后点击字段提取，逐项核对以下测试点。Agent 可能输出错误或缺失，仍需人工审查。没有模型密钥时，可以跳过自动分析/提取，手动选模板和填写。

## 如何完成一次演示

1. 分析记录，确认或更换模板。
2. 提取并复核，保留对比原文的过程，不要批量盲目确认。
3. 对缺失项可补充虚构演示值；也可使用“一键忽略未确定空白”统一注明原因并暂留空。留空不等于合同具备签署条件。
4. 对违约金等未达成一致项，补充双方最终确认的记录或保留待确认，不要因为需要导出就随意编造。
5. 对签字区、排版空白等无需本次填写的位置，说明留空原因。
6. 审查预览；若提示视觉区域核对，下载原件查看图片/图形后再确认。
7. 生成草稿，在 Word 中核对金额、字段位置、溢出、空白与附件。演示文件不要拿去真实签署。

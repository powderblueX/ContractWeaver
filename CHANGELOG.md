# Changelog

## 0.1.0 — Initial development release

- Model-directed supervisor with bounded search/observation/query-refinement and evaluator/targeted-repair loops; repairs are revalidated and independently reviewed before merging, with human approval still mandatory.
- Visible selected actions, user clarification questions and partial-failure guidance; executable coordination scenarios and project capability evidence.

- Centralized, versioned task prompts with input semantics, processing order, typed slot rules, mapping examples and structured output contracts; independent of provider thinking mode.

- Contract-specific harness with explicit step allowlists, shared request/input/time budgets, SQLite run journal and cross-worker leases; owner-gated run history and visible execution summaries.
- Optional provider reasoning effort and short structured decision summaries across all roles; raw provider reasoning is discarded, not persisted or exposed as a complete chain of thought.

- Custody-export regressions: ignore paragraph tab definitions and clause-heading gaps, deduplicate tab-separated blanks, add typed date/choice/money slots and deterministic confirmation/export guards.
- Explicit active-slot model context, whole-contract coverage review with verified quotes, warning-aware batch confirmation, and safe stale-mapping reload guidance.

- Negotiation-record ingestion with TXT, Markdown and DOCX support.
- Separate analysis, extraction and review agents coordinated by a human-reviewed workflow.
- Template recommendations and independent manual library selection.
- Source-line evidence, conflict review, corrections, explicit omissions and versioned DOCX export.
- Original Word templates, deterministic structural slots and fail-closed rendering checks.
- Metadata BM25 retrieval with optional vector rank fusion and bounded usable-template recommendations.
- Text-node-only writing, text-box compatibility synchronization, media preservation checks and explicit visual approval.
- Source-grounded explicit contract-name priority, literal-request fallback and visible unsupported named originals.
- Separate Windows/Linux/macOS setup and startup scripts, Docker Compose configuration and beginner deployment guidance.
- Fictional meeting-minutes example with an expected-review checklist; Windows project-scoped shutdown and optional dependency cleanup, verified without stopping unrelated Node processes.
- Guided review flow, real transport/batch progress, short model field IDs, readable paragraph/table previews, explicit selected-blank grouping and email-only authentication with existing account data preserved.
- Backend-only API credentials, typed configuration and owner-scoped revision-controlled persistence.
- A small `backend/`, `frontend/`, `docs/`, `scripts/` repository layout with bilingual documentation.

This is an early-stage project, not a production-certified or fully validated
template library. Current template coverage and model-test limitations are
documented in [validation](docs/validation.md). The obsolete placeholder library
has been removed after Git recovery verification; original templates remain.
DeepSeek Flash public configuration is provided without a key. See
[deployment](docs/deployment.md) and [maintenance](docs/maintenance.md).
No release tag has been created.
